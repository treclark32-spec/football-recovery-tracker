# Football Recovery and Film Tracker

## Project Description

This application helps football players track their recovery, workouts, and film study in one place.

## Main Features

- Daily soreness and recovery tracking
- Workout logging
- Football film study notes
- Recovery progress dashboard
- AI-powered film summaries and general recovery tips

## Technology Stack

- Frontend: React
- Backend: Node.js and Express
- Database: SQLite
- Containerization: Docker
- CI/CD: GitHub Actions
- Deployment: Render
- AI: AI API integration
